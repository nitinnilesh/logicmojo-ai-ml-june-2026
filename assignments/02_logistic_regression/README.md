# Logistic Regression Assignment

This folder contains a lightweight participant-facing assignment notebook for logistic regression on imbalanced classification data.

## Dataset

Online Shoppers Purchasing Intention dataset. The notebook loads the CSV directly from a public URL.

## Topics Covered

- Binary classification with logistic regression
- Class imbalance analysis
- Stratified train-test split
- Numeric scaling and categorical one-hot encoding
- Baseline logistic regression
- Threshold tuning using predicted probabilities
- Class-weighted logistic regression
- SMOTE on training data only
- Accuracy, precision, recall, F1-score, and confusion matrix
- Business interpretation of precision-recall tradeoff

## Files

- `online_shoppers_logistic_regression_assignment.ipynb`: assignment notebook
