# Medical Insurance Cost Prediction Assignment

This folder contains a participant-facing assignment notebook for multiple linear regression.

Files:

- `medical_insurance_linear_regression_assignment.ipynb`: assignment notebook
- `medical_insurance_linear_regression_solution.ipynb`: solved notebook

The assignment notebook includes auto-download code for the dataset.

Participants should submit:

1. Completed notebook.
2. 5-8 bullet-point summary of findings.
3. Key plots: target distribution, actual vs predicted, residuals, and coefficients.
