# K Nearest Neighbors Assignment

This folder contains a lightweight participant-facing assignment notebook for KNN classification and KNN imputation.

## Dataset

The assignment uses the built-in Wine dataset from scikit-learn. No internet download is required.

## Topics Covered

- KNN classification
- Stratified train-test split
- Importance of feature scaling in KNN
- Choosing the value of `K`
- Cross-validation for model selection
- Euclidean vs Manhattan distance
- Uniform vs distance-weighted voting
- Final model evaluation with accuracy, classification report, and confusion matrix
- KNN imputation for missing values
- Conceptual questions on KNN behavior and limitations

## Files

- `wine_knn_assignment.ipynb`: assignment notebook
