# Datasets

Keep large datasets out of GitHub.

## Eigenfaces PCA Dataset

The Eigenfaces PCA live notebook uses the Hollywood Celebrity Facial Recognition dataset.

Download link: [https://drive.google.com/file/d/18KqTu1Lb5V0svBnnEI44Wk4eI4VT8bhM/view?usp=share_link](https://drive.google.com/file/d/18KqTu1Lb5V0svBnnEI44Wk4eI4VT8bhM/view?usp=share_link)

After downloading, place the file here:

```text
logicmojo-ai-ml-june-2026/datasets/archive.zip
```

The notebook should use this repo-relative path:

```text
datasets/archive.zip
```

If you are running the instructor copy from the local LogicMojo folder, the dataset may also be available at:

```text
/Users/nitinnilesh/LogicMojo/Datasets/archive.zip
```

## Dataset Policy

- Do not commit large dataset files directly to GitHub.
- Commit only dataset instructions, small samples, or download helpers when needed.
- Keep downloaded archives local inside `datasets/`.
