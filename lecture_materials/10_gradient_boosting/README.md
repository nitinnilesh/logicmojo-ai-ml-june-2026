# Gradient Boosting

Live teaching material for the Gradient Boosting lecture held on 19 September 2026.

## Files

- `notebooks/13_gradient_boosting_live.ipynb` - live class notebook.
- `notes/13_gradient_boosting_live_notes.pdf` - live class PDF notes.

## Topics Covered

- Boosting as sequential correction of earlier model errors.
- Gradient boosting regression using residuals and shallow decision trees.
- Learning rate, number of trees, and staged error reduction.
- Gradient boosting classification using log-odds, probabilities, and pseudo-residuals.
- Scikit-learn `GradientBoostingRegressor` and `GradientBoostingClassifier`.
- A real-world Bank Marketing classification example with preprocessing and evaluation.
- An introductory XGBoost implementation and comparison.
