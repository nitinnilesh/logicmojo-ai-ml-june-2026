## Topics Covered in Part 1

- Extending logistic regression from one neuron to a network of neurons.
- Why a hidden layer is needed, using XOR as motivation.
- Network architecture, parameters, weights, biases, and tensor shapes.
- Vectorized forward propagation through a one-hidden-layer network.
- Identity, sigmoid, tanh, ReLU, and Leaky ReLU activation functions.
- Why multiple linear layers need nonlinear activation functions.
- Binary cross-entropy loss for binary classification.
- Chain-rule intuition and gradients for backpropagation.
- Updating weights and biases with gradient descent.
- Stochastic, full-batch, and mini-batch gradient descent.
