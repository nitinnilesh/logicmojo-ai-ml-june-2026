# Principal Component Analysis Notes

PDF notes from the live Principal Component Analysis class.

## Topics Covered

- Introduction to Principal Component Analysis (PCA)
- PCA motivation and dimensionality reduction intuition
- Mean centering and feature scaling
- Projection onto candidate directions
- Variance maximization intuition
- Covariance and covariance matrix
- Eigenvalues and eigenvectors
- Principal component directions
- Projection onto principal components
- Reconstruction from reduced components
- Reconstruction error
- Explained variance ratio and cumulative variance
- Choosing number of principal components
- PCA with real datasets and visualization
- Scaling effects in PCA
- PCA before machine learning models
- PCA limitations
