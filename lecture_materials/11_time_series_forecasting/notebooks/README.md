# Time Series Forecasting Notebook

The cumulative live coding notebook from the Time Series Forecasting classes held on 26 September, 3 October, and 4 October 2026.

## File

- `14_15_16_time_series_forecasting_live.ipynb` - live implementation covering exploration, decomposition, baselines, stationarity, smoothing, ARIMA-family models, time-aware validation, and machine-learning forecasting.

## Dataset

The notebook uses the Bike Sharing Demand training dataset and expects the CSV to be available as `/content/bike_sharing_train.csv` when run in Google Colab.
