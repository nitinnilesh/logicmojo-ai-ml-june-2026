# ML/DS Interview Preparation

Live teaching notes for the ML/DS Interview Preparation class held on 10 October 2026.

## Files

- `notes/17_ml_ds_interview_preparation_notes.pdf` - live class PDF notes.

## Topics Covered

- Choosing target ML and data-science roles and understanding interview stages.
- Revising machine-learning concepts through retrieval, examples, and spoken explanations.
- Structuring technical answers and handling follow-up questions.
- Preparing for end-to-end ML system-design discussions.
- Improving LinkedIn profiles and writing defensible resumes.
- Finding relevant opportunities, interpreting job descriptions, and tailoring applications honestly.
- Asking for referrals and writing focused outreach messages.
- Running mock interviews, answering behavioural questions with STAR, and using feedback loops.
- Preparing for coding rounds and building a repeatable interview-preparation plan.
