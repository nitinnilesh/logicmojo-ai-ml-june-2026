# PyTorch Fundamentals

Participant-facing material for the PyTorch fundamentals class.

## Follow-Along Notebook

[![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/nitinnilesh/logicmojo-ai-ml-june-2026/blob/main/lecture_materials/14_pytorch_fundamentals/notebooks/21_pytorch_fundamentals_follow_along.ipynb)

- `notebooks/21_pytorch_fundamentals_follow_along.ipynb`
- Designed for students to complete alongside the instructor.
- Contains a conditional dependency setup cell for Google Colab.
- Covers tensors, shapes, autograd, `nn.Module`, Fashion-MNIST, DataLoaders, one parameter update, and training and evaluation loops.
- Optional sections cover learning curves, mistake analysis, and saving and loading model weights.

## Running in Google Colab

1. Click the **Open in Colab** badge above.
2. Save a personal copy when prompted.
3. Run the setup cells in order.
4. Complete each TODO during the live class.

A GPU is optional for this notebook. The Fashion-MNIST MLP can also run on CPU.
